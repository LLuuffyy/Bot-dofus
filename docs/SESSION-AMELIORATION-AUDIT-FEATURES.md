## TOP 5 FEATURES À COMPLÉTER (par impact user)

1. **Auto-reconnexion après kick/déco** (Feature #9) — actuellement le bot devient inerte après un kick serveur, l'user doit relancer Dofus manuellement. Bloque les sessions farm longues unattended. Effort estimé 3-4 h (cf. `docs/TODO-AUTO-RECONNEXION.md`). Impact massif sur les sessions nocturnes/scolaires.

2. **LOS Bresenham + multi-cast combat IA** (Feature #1) — les sorts avec `NecessiteLOS = true` (la majorité des sorts élémentaires) sont actuellement castés sans vérif, ce qui fait rater des tours quand un obstacle est entre le perso et la cible. Combiné au multi-cast par tour (drainer les PA), c'est le gain DPS le plus visible.

3. **UI Farm Auto enrichie** (Feature #2) — le bouton header est binaire ; il manque blacklist mob, rayon, rotation multi-cartes et filtre par niveau pour éviter de wipe sur des mobs trop forts. Améliore drastiquement la viabilité du farm autonome (cas user étudiant : Beiloddurul niv 13).

4. **Persistance + graphiques stats session** (Feature #8) — actuellement tout est perdu à la fermeture de Luffy-bot. Un export CSV journalier + un graphe kamas/heure dans le Dashboard rendrait le projet beaucoup plus démontrable pour l'examen scolaire.

5. **Gestion zaap retour banque** (Feature #3) — le workflow `PiloteBanque` ne revient pas toujours proprement sur la map farm après dépôt ; quand `OuvertureDirecte=false`, le retour est best-effort. Affecte directement la cadence kamas/heure si la banque trigger souvent.
